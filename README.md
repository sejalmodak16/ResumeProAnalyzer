# ResumeProAnalyzer 📄

**ResumeProAnalyzer** is an AI-powered resume analysis web application that helps users evaluate and improve their resumes.

## 🚀 Features

* 📊 ATS Score Analysis
* 🧠 Resume Analysis
* 🔍 Skill Matching
* 🔑 Keyword Gap Detection
* 💡 AI-based Recommendations
* 📄 Resume Upload
* 💼 Job Description Matching
* 📱 Responsive Web Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* AI API
* Git & GitHub

## 📂 Project Structure

```text
ResumeProAnalyzer/
├── index.html
├── script.js
└── style.css
```

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/sejalmodak16/ResumeProAnalyzer.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

## 🎯 Purpose

The project is designed to help students and job seekers analyze their resumes, identify skill and keyword gaps, and improve their chances of passing ATS-based resume screening.
